# site-navigation Specification（增量）

## Purpose

在不扩大主内容栏目、不引入史低／商城／战绩／工具类产品栏目的前提下，为站内「AI 问答」增加「更多／我的」入口。

## MODIFIED Requirements

### Requirement: 桌面侧栏内容区含五个栏目

桌面侧栏的内容区 MUST 正好按顺序列出五项：资讯、热点、AI 日报、主题、收藏。分别指向资讯流首页、热点榜、最新日报、主题目录、本机收藏。内容区 SHALL NOT 出现其他栏目。

「更多」区 MUST 包含 Agent、**AI 问答**、关于、更新日志、反馈（顺序可在 Agent 之后插入 AI 问答）。AI 问答是独立问答能力入口，SHALL NOT 被解释为新增主内容栏目，也 SHALL NOT 被解释为史低／商城／战绩／工具类产品栏目。

#### Scenario: 桌面侧栏

- **WHEN** 读者在宽屏（≥961px）打开任一公开页面
- **THEN** 侧栏内容区显示 资讯、热点、AI 日报、主题、收藏；「更多」区包含 Agent、AI 问答、关于、更新日志、反馈

### Requirement: 手机底栏与桌面内容栏目一致

手机底栏 MUST 显示资讯、热点、日报、主题四个栏目，最后加一个「我的」。「我的」页收纳收藏、**AI 问答**、Agent、关于、更新日志、反馈、使用规则和隐私说明，SHALL NOT 再列出已经成为栏目的「主题」。SHALL NOT 因 AI 问答而增加底栏主栏目。

#### Scenario: 手机底栏

- **WHEN** 读者在窄屏（≤960px）打开首页
- **THEN** 底栏从左到右仍是 资讯、热点、日报、主题、我的

#### Scenario: 主题页归属

- **WHEN** 读者在手机上从主题目录进入某个游戏的主题页再返回
- **THEN** 底栏高亮「主题」，返回按钮回到主题目录

#### Scenario: 我的页含问答入口

- **WHEN** 读者打开「我的」
- **THEN** 可见「AI 问答」入口指向 `/ask`
